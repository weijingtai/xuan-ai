# LLM 技术选型与集成方案

## 1. 核心选型

**决定采用:** `flutter_ai_toolkit` + `flutter_ai_providers`

### 2. 决策理由

1.  **开箱即用的 UI 组件**
    *   `flutter_ai_toolkit` 提供了高度封装的 `LlmChatView`，内置了流式打字机效果、输入框、头像展示等标准聊天功能。
    *   可以快速集成到项目中，减少 UI 开发工作量，专注于业务逻辑。

2.  **Provider 扩展性**
    *   虽然官方主要支持 Google 模型，但通过 `flutter_ai_providers` 接口，我们可以自定义实现 `DeepSeekProvider` 和 `NvidiaProvider`。
    *   架构清晰，易于扩展新的模型提供商。

3.  **多模态支持**
    *   Toolkit 原生支持多模态输入（图片、文件），为未来玄学图片识别（如识别手相、面相）预留了可能性。

## 3. 架构设计

### AI Core 抽象层

*   **LLM Provider**: 实现自定义的 `LlmProvider` 接口：
    *   `DeepSeekProvider`: 适配 DeepSeek API (OpenAI 兼容)。
    *   `NvidiaProvider`: 适配 NVIDIA NIM API (OpenAI 兼容)。
*   **Context Management**: 利用 Toolkit 的 `LlmProvider` 接口传递上下文信息（如盘面数据）。

### UI 实现

*   **Chat Window**: 使用 `LlmChatView`。
*   **Customization**: 
    *   通过 `messageBuilder` 自定义消息气泡样式，以符合玄学古风。
    *   通过 `style` 属性调整颜色和字体。

## 4. 后续规划

1.  **Provider 实现**: 编写 `DeepSeekProvider` 和 `NvidiaProvider`。
2.  **UI 适配**: 调整 Toolkit 的默认样式以融入玄学 App 风格。
3.  **工具集成**: 研究如何在 Toolkit 中通过 Function Calling 集成 `DivinationSkillInterface`。
